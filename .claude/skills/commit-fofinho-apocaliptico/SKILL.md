# Commit fofinho mas apocalíptico 🌸💀

Toda mensagem de commit deste projeto segue o padrão pessoal do usuário. Não existe
exceção: commit de rotina, de agente, de hotfix ou de squash merge, todos entram aqui.

## As três regras

1. **Sempre no diminutivo.** `fix` vira "ajustinho", `bug` vira "buguinho", `mapa` vira
   "mapinha", `filtro` vira "filtrinho". O diminutivo aparece no título e no corpo.
2. **Fofinho mas apocalíptico.** Tom carinhoso, meigo, quase infantil — descrevendo algo
   catastrófico, terminal, o fim do mundo. A doçura e o terror convivem na mesma frase.
3. **Muito emoji.** No mínimo 3 no título e vários espalhados pelo corpo. Emoji fofo
   (🌸🐣🧸✨🍼) misturado com emoji de apocalipse (💀🔥☄️⚰️🌪️).

## Formato

```
<tipo>: 🌸 <título no diminutivo, fofinho e apocalíptico> 💀🔥

- 🐣 o que mudou, no diminutivo
- ☄️ por que mudou, com um toque de fim dos tempos
- 🧸 o que ficou de fora, se ficou

Closes #<N>   (quando houver issue)
```

- Mantenha o prefixo convencional em inglês (`feat:`, `fix:`, `refactor:`, `docs:`,
  `chore:`) — é o que o histórico do repositório já usa. Todo o resto é pt-BR.
- Título curto (até ~72 caracteres contando emoji).
- Nada de credencial, chave, token ou dado sensível na mensagem — nem de brincadeira.
- Rodapé de coautoria do Claude, quando aplicável, entra depois do corpo, sem emoji.

## Exemplos

```
fix: 🌸 ajustinho no mapinha antes que o mundo desabe 💀☄️

- 🐣 o `fixAntimeridian` estava deixando a Rússia escorrer pelo mapinha inteirinho
- ☄️ mais um pouquinho e a projeçãozinha levava a civilização junto 🔥
- 🧸 os microestadinhos sem polígono continuam ausentinhos, como sempre foi previsto ⚰️
```

```
feat: 🍼 chatzinho novinho para o último suspiro dos dados 🌪️💀

- ✨ contextinho remontado a cada envio, docinho e implacável
- 🔥 se o recortinho vier vazio, o modelo avisa em vez de inventar o apocalipse
```

```
docs: 🧸 documentaçãozinha atualizada rumo ao vazio 💀✨
```

## Anti-exemplo (não faça)

```
fix: corrige antimeridiano no mapa
```
Sem diminutivo, sem emoji, sem apocalipse. Reprovado. 💀
